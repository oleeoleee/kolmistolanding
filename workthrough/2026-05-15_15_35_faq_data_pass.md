# FAQ 데이터 패스

## 개요
현재 페이지 레이아웃을 유지하면서 auto-family fixture용 FAQ 데이터 계층을 추가했다.
FAQ는 이번 단계에서 data-only로 두고, 추후 가벼운 렌더링 패스가 가능하도록 타입과 문서를 정리했다.

## 주요 변경사항
- 개발한 것: `FaqItem`, `FaqContent`, `faq` config 그룹 추가
- 수정한 것: AURUM DETAIL과 Kolmi/LADA fixture에 실사용형 FAQ 항목 추가
- 개선한 것: fixture 작성 문서에 FAQ 작성 규칙과 data-only 상태 명시

## 결과
- ✅ `npm run lint` 성공
- ✅ `npm run build` 성공
